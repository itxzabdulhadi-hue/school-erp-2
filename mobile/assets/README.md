# App assets

`icon.png`, `adaptive-icon.png`, `splash.png`, and `favicon.png` are generated by
`node scripts/make-assets.js` (brand color via `PRIMARY_COLOR`). They are committed
so EAS builds work out of the box.

For store releases, replace them with designer exports of the school's real logo:

| File | Size | Notes |
|---|---|---|
| `icon.png` | 1024 × 1024 | iOS + Android fallback icon |
| `adaptive-icon.png` | 1024 × 1024 | Android foreground; keep art inside the center 66% (safe zone) |
| `splash.png` | 1284 × 2778 | Portrait splash; keep the mark centered |
| `favicon.png` | 48 × 48 | Expo web only |

Changing these files requires a new native build (see `docs/BRANDING.md`).
